# AetherForge Stream Deck v3.0.5

Included: 10 custom keys, a 5x3 profile bundle, and `profile-layout.json`.

Hotkeys: F13 Start Stream; F14 Starting Soon; F15 Gameplay; F16 Just Chatting; F17 BRB; F18 Sleeping; F19 End Stream; F20 Mute Mic; F21 Stream Ending; F22 Alerts.

Import `AetherForge-v3.0.5.streamDeckProfile`. If your Stream Deck app version does not accept the included System Hotkey instances, create System > Hotkey actions using F13-F22 and the bundled icons; `profile-layout.json` is the portable source of truth. Then bind the same keys in OBS.

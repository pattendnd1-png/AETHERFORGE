# AetherAI v0.3.7 Self-Managing Terminal-Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship AetherAI v0.3.7 as a normal self-managing desktop AI application that requires no terminal commands for normal use and renders through the exact AetherForge Terminal visual/schema authority.

**Architecture:** Start from the verified green `~/Downloads/AetherAI-v0.3.6-work` donor and create a new isolated `~/Downloads/AetherAI-v0.3.7-work`. Establish the shared AetherForge UI contract/renderer before adding new user surfaces, then move AetherAI onto that renderer, add native Files/attachments, lifecycle/update/rollback, in-app health/diagnostics, model management, and permission/activity UX. Preserve the native local ChatGPT Library and zero-cost/local-inference constraints throughout.

**Tech Stack:** Rust 2024 workspace, `winit`, `wgpu`, `glyphon`, `cosmic-text`, existing AetherAI storage/import/retrieval/chat crates, SQLite, SHA-256 release verification, user-owned atomic release directories.

**Spec:** `docs/superpowers/specs/2026-09-05-aetherai-v0.3.7-self-managing-terminal-parity-design.md`

# v2.1.16 Persistent Session Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make normal-profile website logins durable across browser restarts while keeping Private browsing fully ephemeral.

**Architecture:** `aether-profile` owns profile storage paths and privacy semantics. `aether-engine-servo` creates Servo and every WebView using one active profile context for the browser lifetime, with normal sessions backed by an on-disk profile directory and Private sessions backed by a temporary directory.

**Tech Stack:** Rust 2024, Servo 0.5.0, std filesystem/temp directories, existing Aether profile/session crates.

**Spec:** `docs/superpowers/specs/2026-09-10-v2.1.16-session-media-design.md`

## Global Constraints
- Canonical release version is `2.1.16`.
- Normal browsing persists website state until explicit sign-out or site-data clearing.
- Private browsing never reads or writes normal-profile site state.
- Do not log cookies, tokens, authorization values, or storage payloads.
- Preserve v2.1.15 right-rail viewport reclamation and performance behavior.

# OpenDeck+ v2.0.30 Dial Stacks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship OpenDeck+ 2.0.30 with persistent, hardware-aware Dial Stacks on top of the exact 2.0.29 donor.

**Architecture:** Extend the existing `ControlSlot` model with an optional stack, keep existing single-dial bindings intact as rollback/fallback state, and route stacked dial execution through the active stack entry. The existing editor reducer remains the source of truth for state changes; Rust mirrors and validates the model for persistence and device rendering.

**Tech Stack:** React 19 + TypeScript/Vitest, Tauri 2 + Rust, HID Stream Deck+ runtime, Python qualification contracts.

**Spec:** `docs/superpowers/specs/2026-09-17-opendeck-v2.0.30-dial-stacks-design.md`

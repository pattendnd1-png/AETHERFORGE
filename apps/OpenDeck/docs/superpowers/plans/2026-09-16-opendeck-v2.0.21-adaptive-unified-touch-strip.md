# OpenDeck+ 2.0.21 Adaptive Unified Touch Strip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add segmented, unified, and application-adaptive 800×100 Stream Deck+ touch-strip behavior without changing canonical editor geometry.

**Architecture:** Extend the durable page model with a touch-strip configuration and unified touch slot; resolve effective presentation from current application context; render the same decision in React and Rust hardware output; route unified HID touch events to one slot while retaining full coordinates.

**Tech Stack:** React 19, TypeScript, Vitest/Testing Library, Tauri 2, Rust 2024, serde, existing HID runtime and image renderer.

**Spec:** `docs/superpowers/specs/2026-09-16-opendeck-v2.0.21-adaptive-unified-touch-strip-design.md`

## Global Constraints

- Target version is 2.0.21; 2.0.20 is the rustfmt-only closure carried forward.
- Keep 1536×1024 qualification geometry unchanged.
- Old schema-version 1 workspaces must load with touch-strip defaults.
- No background service/autostart.
- Do not change key/dial/Twitch/OBS behavior.
- Preserve exact touch coordinates for unified input.
- Active application detection must fail closed to `null`, never block editor startup.
- Dial Stacks are deferred to 2.0.22.

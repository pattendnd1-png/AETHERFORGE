# OpenDeck+ 2.0.9 Render-Parity + Performance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild OpenDeck+ 2.0.9 so the real 1536×1024 application matches the approved canonical render while meeting the explicit UI, hardware, startup, frame-pacing, search, persistence, and idle-efficiency budgets.

**Architecture:** Preserve the qualified 2.0.8 workspace/action/HID model and replace only the shell/presentation path. Split the visual shell into focused memoized components, use a fixed-height virtualized Action Library viewport for large catalogs, add deterministic qualification/demo state, and add instrumentation that records real browser-side interaction latency and Rust-side HID/persistence timings without blocking normal interaction. Qualification remains host-first: 2.0.8 stays active until functional, visual, performance, build, and Stream Deck+ gates all pass.

**Tech Stack:** React 19, TypeScript 5.9, Vite 7, Vitest, Tauri 2, Rust 1.98.1, CSS Grid/Flexbox, inline clean-room SVG glyphs, Python 3 visual/contract scripts.

**Spec:** `docs/superpowers/specs/2026-09-16-opendeck-v2.0.9-render-parity-performance-design.md`

## Global Constraints

- Canonical baseline is OpenDeck+ 2.0.8; do not accept failed 2.0.6/2.0.7 candidates as rollback authorities.
- Canonical visual is `docs/superpowers/specs/OpenDeck-v2.0.9-CANONICAL-UI-TARGET.png` at exactly 1536×1024.
- Preserve qualified 2.0.8 Twitch auth, Stream Deck Plus HID runtime, Keys/Dials filtering, Press / Rotate Left / Rotate Right / Press+Rotate Left / Press+Rotate Right, persistence, action execution, no-background-service policy, and no-autostart policy.
- Dial Stacks are not part of 2.0.9; they remain targeted for 2.0.10.
- Primary visual region geometry tolerance is ±2%; device element size tolerance is ±8%; edge similarity minimum is 0.93; pixel/color similarity minimum is 0.82; human visual approval is mandatory.
- Warm-start p95 ≤ 650 ms; cold-start p95 ≤ 1200 ms.
- Sidebar selection p95 ≤ 35 ms; control-selection-to-configuration p95 ≤ 50 ms; Keys↔Dials p95 ≤ 35 ms; assignment p95 ≤ 60 ms; profile switch p95 ≤ 120 ms; 5,000-action search p95 ≤ 70 ms.
- ≥95% frames ≤16.7 ms, ≥99% ≤33.3 ms, no frame >50 ms during qualification interactions.
- HID decode→dispatch p95 ≤10 ms and HID decode→visible feedback p95 ≤25 ms.
- Idle CPU average ≤1.5% of one logical CPU; resident-memory target ≤300 MiB.
- No lint suppression, no test weakening, and no cutover before every hard gate is green.

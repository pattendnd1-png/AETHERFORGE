# OpenDeck+ v2.0.30 Dial Stacks Design

## Goal
Add first-class Dial Stacks to the exact OpenDeck+ 2.0.29 source while preserving the current editor shell, Stream Deck+ hardware runtime, startup behavior, and rollback safety.

## Baseline
- Exact donor: OpenDeck+ 2.0.29 source archive SHA256 `3beee5ad7458942262fc250614963f4991148726274961defe3c6c00ae566234`.
- Target: OpenDeck+ 2.0.30.
- No background services or autostart.
- Existing 2.0.29 install remains untouched until host qualification passes.

## Dial Stack Model
A dial may optionally own one `DialStack` with ordered entries. Each entry stores its own complete dial interaction binding map and label. The stack stores `activeIndex` and behavior `pressCycle`.

Pressing a stacked dial cycles the active entry. Rotate-left/right and press+rotate-left/right execute the active entry's bindings. Stack state is ordinary workspace state so it persists through saves, profile duplication/export/import, app restart, and hardware sync.

## Editing
The Dials action library exposes `Dial Stack`. Assigning it to a dial creates a stack without destroying the dial's pre-stack bindings. The inspector exposes stack entries, active selection, rename, add, reorder, remove, and remove-stack controls. Normal action assignment/configuration edits the active stack entry while a stack exists.

## Display
The dial label reflects the active stack entry. The Stream Deck+ touch strip displays the active stack label and position (`n / total`) over the corresponding dial region in both Studio and hardware rendering.

## Compatibility
Existing workspaces deserialize with `dialStack = null`. Rust persistence explicitly carries the stack data so it is never dropped on save. Non-dial controls may not contain dial stacks. Stack indices and entry ids are validated.

## Qualification
Add targeted frontend tests, Rust persistence/render tests, and a fail-closed v2.0.30 source contract. Keep the 2.0.29 UI shell and qualification architecture unchanged except version normalization and Dial Stack-specific checks.

# OpenDeck+ 2.0.32 Action Wheel Design

**Baseline:** fully qualified OpenDeck+ 2.0.31.

**Goal:** add a Stream Deck+ Action Wheel dial container without changing the qualified 2.0.31 shell or Dial Stack behavior.

Each Action Wheel owns ordered entries with stable IDs, labels, press-action bindings, and one active index. Ordinary rotation (including press+rotate) changes the active index with wraparound. Dial press and matching touch-strip tap execute the active entry's press action. Action Wheel and Dial Stack are mutually exclusive on one dial.

The editor exposes Action Wheel in the Dials action library and provides keyboard/click-accessible add/select/rename/reorder/remove controls. The normal Action Inspector edits the selected wheel entry. Dial and touch-strip presentation shows the active entry and `index / total` status.

Persistence extends the schema-compatible control-slot model with an optional `actionWheel` field using serde/default handling on the Rust side. Copies and duplicated profiles regenerate entry IDs. Rust validation rejects wheels on non-dials, invalid behavior, empty/oversized wheels, out-of-range selection, duplicate IDs, empty labels, non-press wheel bindings, or a dial containing both a stack and wheel.

Qualification preserves the existing frontend/Rust/Tauri/hardware/visual gates and adds dedicated Action Wheel source/model and regression coverage before activation.

# AetherForge BEACN Control v0.1.15 — Private DSP Windows Reforge Design

## Goal

Reforge AetherForge BEACN Control against the user-supplied BEACN Windows installer set while preserving the v0.1.13 microphone-availability protections and enforcing complete separation from AetherStream/system DSP.

## Reference authority

The reference installers are static-only inputs:

- `BEACN+Setup+V1.2.62.0.exe` — historical BEACN App generation.
- `BEACN+Setup+V1.4.1.21.exe` — current supplied BEACN App generation and primary reference.
- `BEACN+Link+App+Setup+V1.0.4.0(1).exe` — separate BEACN Link companion reference.

They are never executed. Only static package/resource evidence is used. Original DragonGlass visuals replace proprietary artwork.

## Hard ownership boundaries

1. Linux `snd_usb_audio`/ALSA/PipeWire permanently own the physical BEACN Mic audio interfaces.
2. Direct BEACN vendor USB control remains blocked; the runtime does not depend on `beacn-lib`.
3. AetherStream and every AetherForge system-DSP API are forbidden dependencies for this application.
4. The application never changes the system default source or sink.
5. The raw BEACN PipeWire source remains available even if BEACN Control is stopped or crashes.
6. BEACN Control may create and remove only its own namespaced private virtual source and helper streams.

## Private audio architecture

```text
Physical BEACN Mic
    ↓  (existing ALSA/PipeWire source; never replaced)
pw-record targeted explicitly at the BEACN source
    ↓  raw float32 mono, 48 kHz
AetherForge BEACN private Rust DSP worker
    ↓
private FIFO
    ↓
PipeWire Pulse module-pipe-source
    ↓
AetherForge BEACN Processed (separate selectable source)
```

The virtual source is **not** selected as a default automatically. Applications may explicitly choose it. Stopping the private DSP unloads only the module created by this app and leaves the raw BEACN source untouched.

## DSP chain

The private Rust engine applies, in order:

1. input gain;
2. 9-band microphone EQ;
3. noise suppression;
4. expander;
5. compressor;
6. de-esser;
7. exciter;
8. mic output gain;
9. bounded safety limiter.

The algorithms are clean-room implementations based on the exposed control semantics. The Windows installers do not reveal proprietary DSP algorithms, so v0.1.15 does not claim bit-identical Windows processing.

Headphone controls stay scoped to BEACN Control state and the BEACN endpoint. v0.1.15 does not intercept or process global system playback to achieve headphone parity, because doing so would violate the system-DSP isolation rule.

## Windows-style UI behavior

Retain the BEACN 1.4-inspired workstation introduced in v0.1.13:

- dedicated BEACN/AetherForge header;
- Live Profile strip with autosave and snapshots;
- device/module rail;
- Equalizer & Enhancement anchor surface;
- secondary processing tabs for Compressor, Expander, Noise Suppression, De-Esser, Exciter, and Headphones;
- end-of-chain Mic Output surface;
- voice recorder;
- 10-band per-ear headphone EQ state;
- balance, mono, monitor, presets, and binaural-personalization state;
- responsive/scroll-safe DragonGlass layout.

Add a Private DSP status/control surface with explicit Raw Source, Processed Source, Start/Stop, state, and isolation badges.

## Failure behavior

- If `pw-record`, `pactl`, `mkfifo`, or `module-pipe-source` is unavailable, the app reports private DSP unavailable and leaves raw BEACN audio untouched.
- If capture or FIFO output fails, the private worker stops and unloads only its own module.
- No recovery path restarts AetherStream or modifies its state.
- Existing safe BEACN duplex-profile repair remains limited to the BEACN card and never changes defaults.

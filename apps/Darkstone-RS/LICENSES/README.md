# Darkstone-RS licensing boundary

Darkstone-RS is a clean-room reimplementation and does not distribute original Darkstone game data.

Original Darkstone archives, models, textures, audio, music, cinematics, maps, scripts, text, and other copyrighted assets are user-supplied inputs and must not be committed to or packaged with this repository.

Only synthetic fixtures created specifically for Darkstone-RS tests may be committed under `tests/fixtures/`.

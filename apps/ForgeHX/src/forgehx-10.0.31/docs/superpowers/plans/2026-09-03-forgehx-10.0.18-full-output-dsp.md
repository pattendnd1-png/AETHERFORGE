# ForgeHX 10.0.18 Full Output DSP Control Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add full-range live output-DSP controls to ForgeHX while AetherStream 10.2.33 remains authoritative system-audio owner.

**Architecture:** Mirror AetherStream's serialized output-DSP types in `forgehx-core`, route ForgeHX GUI commands through the existing daemon, and add a small typed AetherStream runtime client using postcard-framed Unix IPC. Persist only ForgeHX editor state locally and never mutate PipeWire default input/output selection.

**Tech Stack:** Rust 2021, serde/serde_json, postcard, uuid, std UnixStream, egui/eframe, existing ForgeHX JSON IPC.

**Spec:** `docs/superpowers/specs/2026-09-03-forgehx-10.0.18-full-output-dsp-design.md`

## Global Constraints
- Release identity is exactly `10.0.18` with one canonical artifact set.
- Requires AetherStream 10.2.33 for live output DSP.
- Preserve `HyperX SoloCast 2 Analog Stereo` input/output selection exactly.
- Preserve ForgeHX 10.0.17 microphone bridge architecture.
- No `wpctl set-default`, `pactl set-default-source`, `pactl set-default-sink`, or equivalent routing mutation in output-DSP code.
- New ForgeHX IPC commands require protocol 12.

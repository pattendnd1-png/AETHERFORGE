# ForgeHX 1.1.0 VoicePilot DSP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver ForgeHX 1.1.0 with a local VoicePilot adaptive microphone DSP contract, built-in AEC/noise-processing engine, multiband EQ, Bass/Treble Boost, expanded dynamics, and GUI controls while preserving the HyperX-only product boundary.

**Architecture:** Extend `forgehx-core` with validated DSP and VoicePilot configuration/state types. Extend `forgehx-dsp` with Sonora-backed 10 ms frame processing plus local tone/dynamics and bounded adaptive-target analysis. Expose the complete configuration on the existing Input DSP GUI and preserve the current daemon/profile IPC path.

**Tech Stack:** Rust 2021, serde, Sonora 0.2, egui/eframe, PipeWire/WirePlumber integration already present in ForgeHX.

**Spec:** `docs/superpowers/specs/2026-08-24-forgehx-1.1.0-voicepilot-dsp-design.md`

## Global Constraints

- Release identity is exactly `1.1.0` with `pkgrel=1`.
- Preserve `hidapi = { version = "2", default-features = false, features = ["linux-native"] }`.
- HyperX-only visible inventory remains intact.
- No JamesDSP or EasyEffects.
- No general playback DSP path; playback is reference-only for AEC.
- Name-only matching never grants proprietary writes.

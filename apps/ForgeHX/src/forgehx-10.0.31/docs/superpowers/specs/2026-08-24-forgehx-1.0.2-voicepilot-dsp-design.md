# ForgeHX 1.1.0 VoicePilot Microphone DSP Design

## Goal

ForgeHX 1.1.0 provides a HyperX-microphone-only, local-first voice-processing chain that automatically keeps speech clear, full, controlled, and intelligible without a general playback-effects path.

## Signal path

`HyperX Mic -> input trim -> high-pass -> AEC3 -> noise reduction -> expander/gate -> bass/treble tone -> multiband EQ -> parametric/dynamic EQ -> de-esser -> multiband compressor -> voice enhancer -> main compressor -> saturation -> limiter -> output trim -> ForgeHX Processed Mic`.

The selected system output is tapped only as the AEC render reference. It is never exposed as a ForgeHX playback DSP chain.

## Built-in cleanup

- Use Sonora 0.2.x as the Rust AEC3/noise-suppression/AGC processing foundation.
- 48 kHz mono capture, 10 ms / 480-sample processing frames.
- AEC and noise reduction default enabled.
- AEC failure or reference loss must degrade to mic processing without AEC rather than taking the mic offline.
- No JamesDSP or EasyEffects.

## Full-range tone and dynamics

- 8-band editable parametric EQ with 20 Hz–20 kHz range, ±24 dB gain and Q 0.1–18.
- Four-band tone section with user-adjustable band gain and crossover metadata.
- Dedicated Bass Boost: low-shelf-style control, bounded to 0–12 dB.
- Dedicated Treble Boost: high-shelf-style control, bounded to 0–12 dB.
- Dynamic EQ controls for boom/mud/harshness correction.
- De-esser, four-band compressor, main compressor with parallel mix, saturation and limiter.
- Voice enhancer macros: warmth, body, clarity, presence, air and depth.

## VoicePilot adaptive sub-core

VoicePilot never blocks the realtime audio path. It analyzes rolling windows and emits bounded target parameters. The DSP interpolates toward those targets.

Automatic domains:
- noise reduction
- AEC state/reference health
- input/output headroom
- gate threshold
- bass/treble boost
- low-mid body/mud correction
- presence/air
- de-essing
- multiband and main compression
- output loudness

Every adaptive control is bounded by user-safe minimum/maximum values and a rate limit. Each domain supports Auto, Manual, Locked, or Bypassed behavior.

Default target is `Broadcast Full`: controlled warmth/body, clear upper mids, moderate air, consistent loudness, adaptive bass/treble, and conservative de-essing.

## UI

Input DSP exposes a Basic view with:
- VoicePilot on/off
- target voice profile
- adaptation strength
- Noise Reduction
- Echo Cancellation
- Bass Boost
- Treble Boost
- Warmth
- Fullness/Body
- Clarity
- Presence
- Air
- Compression
- Output level

Advanced view exposes full EQ, multiband tone/compression, gate, dynamic EQ, de-esser, saturation, limiter, and automation modes.

## Safety and compatibility

- HyperX microphone devices only.
- Preserve ForgeHX 0.6.0 HyperX-only inventory behavior.
- Preserve exact hardware ownership rules.
- No name-only proprietary write authority.
- DSP output remains `ForgeHX Processed Mic`.
- If Sonora/AEC runtime cannot initialize, continue with the rest of the microphone chain and report degraded state.
- Release identity is exactly ForgeHX 1.1.0. No RC/revision/r-number artifact suffixes.
